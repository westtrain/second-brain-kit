# 저장과 접근 범위

실제 개인 기록은 공개 toolkit과 별도 저장소에서 보관한다. 초기 생성되는 브레인에는 원격이 없다.
업무 기록은 허용된 별도 업무 저장소에 두며 개인 브레인·개인 GitHub로 원본·색인·출처를 복사하지 않는다.
일반화한 경험을 전달할 때도 특정 검토 본문에 대한 사용자 승인과 해당 조직의 허용 범위가 필요하다.
비밀번호·API 키·복구 코드·인증서 비밀키·불필요한 고객 식별정보는 저장하지 않는다.
기계 패턴 검사는 정보의 민감도·반출 가능성을 완전히 판단하지 못한다.
저장소의 존재, 파일 쓰기 권한, GitHub 인증은 자료 저장·공개 승인과 별개다.
새 원격·공개 범위·백업 위치는 명시적으로 승인한 경우에만 설정한다.
AI 서비스에 입력한 내용은 해당 서비스에서 처리된다. 로컬 파일이라는 이유로 로컬 추론이라고 설명하지 않는다.
