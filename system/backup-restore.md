# 로컬 백업과 복원

scripts/backup.py는 Git 이력과 등록된 worktree의 미커밋 자료를 함께 검증 가능한 로컬 스냅샷으로 보관한다.
대상 경로·scope를 사용자가 선택한다. 개인·업무 보관 위치를 분리하고 금지 파일과 symlink를 거부한다.

```bash
python3 scripts/backup.py --help
```

실제 백업 위치·주기·외부 업로드는 자동 설정하지 않는다. 복원은 새 경로에 만들고 기존 기록을 덮어쓰지 않는다.
백업에는 미커밋 기록이 포함될 수 있으므로 내용을 GitHub 이슈·공개 저장소에 올리지 않는다.
