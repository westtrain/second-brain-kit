# 문서 규칙

파일명은 lowercase-kebab-case.md, 링크는 표준 Markdown 상대 링크를 사용한다.
내용 문서에는 status(draft/confirmed/archived), updated(YYYY-MM-DD), source를 둔다.
프로젝트에는 as_of와 Current Status / Next Actions / Blockers / History / Decisions 절을 둔다.
updated는 편집일, as_of는 현재 상태 기준일이다. 날짜·성과·역할·완료 여부를 추측하지 않는다.
불확실한 내용은 draft이며 source를 미확인으로 유지한다. 세션 observed가 월 단위/unknown이면 일자를 만들어내지 않는다.
