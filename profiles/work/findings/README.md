# 미뤄 둔 문제

지금 진행하는 프로젝트와 별개로 발견했지만 아직 처리하지 못한 결함을 기록한다.
단순 아이디어는 inbox, 프로젝트 완료에 필요한 정상 작업은 해당 프로젝트 세션에 둔다.
증상·근인·범위·영향·미확인·다음 행동과 근거를 쓴다. 같은 문제는 기존 기록을 갱신한다.
priority는 긴급/높음/보통/낮음, state는 열림/처리중/해결됨/안 고치기로 함이다.
내용 metadata는 status·updated·source, 문제 metadata는 priority·state·found_by·discovered를 포함한다.
파일명은 발견일-짧은-이름.md다. 열린 문제를 우선순위 순으로 아래 목록에 연결한다.
실제 장애에서 발견했다면 incident와 finding을 양방향으로 연결한다.
