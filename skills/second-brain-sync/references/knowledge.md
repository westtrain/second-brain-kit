# 지식 수집·추출·활용

선택한 브레인의 system/knowledge-workflow.md와 docs/knowledge-walkthrough.md를 읽는다.
이 자료는 도구와 절차 안내이며 설치된 스킬 폴더에 실제 사용자 기록을 쓰지 않는다.

- “이 글/PDF 발췌/영상 전사 저장”: 지정된 텍스트와 출처만 capture. URL만 받았다면 사용 가능한 도구로 읽을 수 있는지 확인한다.
  네트워크·파일 접근이 없으면 실제로 읽었다고 말하지 않는다. 원문 전체 대신 보관 가능한 발췌와 요약을 우선한다.
- “이 경험에서 배운 점 정리해서 저장”: 기존 지식과 같은 질문·범위를 비교하고 canonical ID를 정한다.
  근거를 context로 읽고 claim별 출처·해시·발췌와 적용 조건을 작성해 distill한다.
  여러 문서를 합쳐도 요약 이상의 새 판단이 없으면 synthesis를 억지로 만들지 않는다.
- “전에 배운 걸 이번 작업에 적용”: catalog → 관련 context → 조건/반례 비교. 최신 상태는 snapshot으로 별도 확인한다.
- 질문·퀴즈·보고서·선택지 비교: 답변/해설의 핵심 주장과 출처를 연결하고 미확인을 표시한다. 저장은 요청했을 때만 한다.
- “생각이 바뀐 이유”: 과거와 현재 조건을 비교한다. 예전 판단을 지우지 않고 변경 이유와 새 근거를 남긴다.

쓰기 JSON은 knowledge_workflow.py의 capture/distill로 전달한다. 기본 review, 명확한 일반 저장은 routine이다.
원격을 새로 연결하거나 사용자 자료를 공개 킷으로 가져오지 않는다. source 해시/quote 검사는 의미상 타당성을 보증하지 않는다.
현재 상태·사실 여부·공개 가능성은 각각 확인한다. 어떤 문서를 읽었는지와 해당 자료가 답하지 못하는 부분을 결과에 표시한다.
